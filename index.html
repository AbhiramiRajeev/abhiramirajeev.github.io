Selected projects

A selection of backend projects exploring distributed scheduling, real-time communication, API design, and event-driven processing.

Distributed Cron & Job Queue Manager

A distributed job platform built around separate scheduler and worker services. The scheduler reads job definitions from PostgreSQL, calculates the next run time from cron expressions, and publishes due jobs to Kafka. Analyzer workers consume jobs, execute them, track progress, and update PostgreSQL and Redis with execution state.

Go · Kafka · PostgreSQL · Redis · Cron · Worker concurrency

Pulse Chat Platform

A real-time chat backend split into an API gateway and a chat service. The gateway handles HTTP and WebSocket connections, validates JWTs, and communicates with the chat service over gRPC. PostgreSQL stores users, rooms, and memberships; MongoDB stores messages; Redis Pub/Sub distributes new messages to gateway WebSocket hubs. Client message IDs support safe retries without creating duplicate messages.

Go · gRPC · WebSockets · JWT · PostgreSQL · MongoDB · Redis

View source on GitHub ↗

StyleHub E-Commerce Backend

A Go REST API for an online clothing store, covering customer and admin workflows. It includes JWT-based registration and login, product search and filtering, category management, shopping cart operations, checkout with stock validation, order history, and role-protected product and order administration. PostgreSQL provides relational persistence, with Docker Compose for local setup.

Go · REST APIs · PostgreSQL · JWT · Role-based access · Docker

View source on GitHub ↗

AIRO-Analyzer

A real-time authentication event analysis engine built in Go. It consumes login events from Kafka and checks for suspicious activity, including repeated failed login attempts within a sliding time window and events from suspicious IP addresses. Redis maintains the detection state, while PostgreSQL stores identified security incidents. The service also publishes detected incidents to Kafka for downstream consumers.

Go · Kafka · Redis · PostgreSQL · Event-driven processing
